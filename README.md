# AIProof — career-intelligence for the 2026–2035 AI shake-out

**Live:** <https://aiproof.fastinfer.org/>

AIProof is a research project by **[FastInfer Inc.](https://fastinfer.org)** that ranks **1,000+ technology roles** by their expected resilience to AI automation over **2026–2035**. Each role is scored across **8 dimensions** — four base (demand, automation resistance, skill depth, strategic importance) and four derived (human judgment, stakeholder interaction, AI augmentation potential, regulatory relevance). Live posting signals from 5 public job feeds refresh weekly.

The site presents the full ranking, per-role profiles with score breakdowns, side-by-side comparisons, methodology, sources, and limitations. All data is downloadable as CSV.

## Running locally

```bash
docker compose up -d --build
docker compose exec api python manage.py migrate
docker compose exec api python manage.py load_roles --wipe
docker compose exec worker python manage.py refresh_postings   # optional — pulls live data
```

Open <http://localhost:9012/>. Five containers run: API (gunicorn), Celery worker, Celery beat, Postgres, Redis.

### Dev loop

```bash
docker compose exec -w /app api ruff check .
docker compose exec -w /app api python -m pytest -q
docker compose exec api python manage.py validate_data
```

These same checks run in CI on every push and PR ([.github/workflows/deploy.yml](.github/workflows/deploy.yml)) and gate the deploy. After editing `web/apps/roles/scoring.py`, re-derive every role with `load_roles --wipe` and confirm integrity with `validate_data`.

## Repository layout

```text
web/                 Django app (apps: core, roles, reports)
data/roles.csv       canonical 1,000+ role roster with base scores
data/processed/      pipeline outputs (rankings, metrics, signals)
scripts/             crawlers, cleaning, analysis, SVG chart generators
charts/              SVG charts (regenerated by the pipeline)
docs/                role taxonomy, career paths, AI-impact analysis
METHODOLOGY.md · INSIGHTS.md · REPORT.md · PLAN.md
```

Data distinguishes real sources (BLS, ISC2, Levels.fyi, Stack Overflow, Gartner, McKinsey, WEF, GitHub Octoverse — cached snapshots audited against the URLs in [METHODOLOGY.md](METHODOLOGY.md)) from clearly-labeled simulated signals via a `data_kind` field on every row. Regenerate the offline analysis and charts with `python3 scripts/run_pipeline.py` (no third-party dependencies).

## Limitations

- **Geography:** US/EU bias; other markets have different curves.
- **Seniority:** senior-IC framing; junior-market dynamics are worse across the board.
- **Time horizon:** a 5–10 year window — a single foundation-model breakthrough or regulatory shift could re-rank. Re-evaluate annually.
- **Industry:** tech-product / FAANG-adjacent assumed; regulated industries shift the rankings.

This is a frame for thinking, not a forecast. Full detail on the [`/limitations/`](https://aiproof.fastinfer.org/limitations/) page.
