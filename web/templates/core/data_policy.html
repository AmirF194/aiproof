AIProof publishes scores derived from public data feeds. This page documents what we collect, where it comes from, how often we refresh it, and how we handle takedown requests.

What we store

  • Public posting metadata: title, company, location, posting date, public URL, AI-mention flag. Stored in data/raw/*.csv.
  • Aggregated counts per role: derived metrics joined to the 1,000-role roster. Stored in data/processed/role_postings_live.csv.
  • No personal data. We never store applicant names, email addresses, or identifiable user-side information.
  • No cookies for tracking. Only Django session cookies for admin login; no analytics, no ad tech.

Crawler ethics

  • Every feed we crawl publishes an explicit public API or no-auth JSON endpoint that invites programmatic access.
  • We respect rate limits — each crawler runs once a week with a small (≤80) per-company fan-out.
  • We do not scrape paywalled content, login-gated job boards, or any site whose robots.txt disallows our user agent.
  • Identifiable User-Agent: aiproof-research/1.0 (+https://aiproof.fastinfer.org).
  • If a source asks us to stop, we stop — see Takedowns below.

Score updates

Live posting metrics refresh weekly. The 8 score dimensions are re-derived deterministically on every load_roles run; the underlying 4-axis calibration is reviewed annually with a published changelog. Major methodology changes are versioned and noted in the methodology.

Takedowns & corrections

If you operate a data source we crawl and want us to stop, or if you spot an error in a role score, email contact@fastinfer.org. We action takedown requests within 7 business days. Corrections are handled on a best-effort basis with a published changelog when the methodology changes as a result.

Licence

Our derived scores, prose, and visualisations are released under CC BY 4.0 — you can share, adapt, and build on them with attribution. Upstream feeds retain their original licences; the sources page lists each one.
