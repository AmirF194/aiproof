# AIProof — Professionalisation Plan

Tracking the work to transform AIProof from a static ranking into a credible
career-intelligence product. Each phase ships independently behind CI/CD and
is verified live before the next starts.

**Status legend:** `[ ]` not started · `[~]` in progress · `[x]` shipped · `[!]` blocked

---

## Constraints (binding)

- **No fabricated sources.** Every source URL we cite must resolve to a real page that supports the claim.
- **No invented citations.** Per-role narrative fields (`why_ai_resistant`, `key_skills`, `transition_paths`, etc.) are either (a) sourced from a real public dataset like O\*NET, or (b) generated by a **deterministic formula over existing sub-scores**, with the formula published in `/report/methodology/`. Never hand-written or LLM-imagined per-role prose.
- **No overpromising.** Language is restrained ("estimate", "directional analysis", "based on the methodology below"), never "guaranteed" or "definitive."
- **Preserve FastInfer branding.** Footer signature + attribution stays on every page.
- **No break in the live site.** Every phase is verified locally with docker compose before push, and verified live after deploy.

## Phase 1 — Schema + algorithmic enrichment   `[x]`

**Goal:** Add 8 new structured fields to every role, populated deterministically.

- Migrations: add to `Role`
  - `seniority_level` (Junior / Mid / Senior / Staff / Principal / Director / VP / C-suite — derived by parsing the title prefix)
  - `role_family` (sub-grouping within category, e.g. *Engineering → Backend*)
  - `human_judgment_score` 0–10 — formula: weighted blend of automation_resistance × skill_depth × category coefficient
  - `stakeholder_interaction_score` 0–10 — formula: category coefficient × seniority multiplier
  - `physical_world_dependency_score` 0–10 — formula: small for SWE, larger for Security/Infra/Hardware roles
  - `ai_augmentation_potential_score` 0–10 — formula: inverse of automation_resistance bounded by skill_depth
  - `regulatory_relevance_score` 0–10 — formula: category coefficient (Security, Compliance, Leadership boost)
  - `confidence_score` 0–100 — coverage metric: are there live postings, an O\*NET match, recent metrics, etc.
- Algorithmic narrative fields stored on Role:
  - `why_ai_resistant` — templated from top 2 sub-scores using fixed prose templates
  - `why_ai_exposed`  — templated from bottom 2 sub-scores
- `last_updated` `DateTimeField(auto_now=True)`
- Update `load_roles` to compute & write all new fields at load time, idempotent.
- All formulas live in `apps/roles/scoring.py` so they're testable and citable.

**Deliverable:** schema migration, 1,000 roles backfilled, no UI changes yet.

## Phase 5 — SEO + structured data   `[x]`

**Goal:** Index-quality metadata so the site ranks for real career queries.

- Per-role `<title>`/`<meta description>` based on role + tier + seniority
- Open Graph + Twitter card metadata in `base.html` with per-page overrides
- `sitemap.xml` (Django sitemaps framework, all roles + categories + tiers + reports)
- `robots.txt` allowing crawl, pointing at sitemap
- JSON-LD `Article` schema on each role page, `Organization` schema for FastInfer
- Canonical URLs
- Per-role "Related roles" section linking to adjacent roles in the same category (also helps with internal linking)

**Deliverable:** all SEO surfaces live, validated against Google's rich-results test.

**Goal:** Lift the live-data coverage from 141/1000 roles upward, with credible sources.
